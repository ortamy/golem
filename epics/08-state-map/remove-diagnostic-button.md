# Юзерстори: Убрать кнопку «Пройти диагностику»

**Как пользователь, я хочу видеть в разделе карты только актуальные действия, чтобы интерфейс не отвлекал меня устаревшим сценарием диагностики.**

Кнопку «Пройти диагностику» необходимо удалить из интерфейса, маршрутов и связанных подсказок. После удаления не должно остаться пустого места, неработающих ссылок или элементов, предлагающих прежний сценарий.
