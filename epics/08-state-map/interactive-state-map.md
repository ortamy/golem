# Юзерстори: Интерактивная карта состояний по кнопке «Карта»

**Как исследователь, я хочу открывать интерактивную карту состояний по кнопке «Карта», чтобы видеть переходы между состояниями и выбирать нужное состояние для изучения.**

Кнопка «Карта» должна вести к рабочей карте состояний с узлами, связями и краткими пояснениями. Карта должна поддерживать переходы к связанным материалам и корректно работать в общей навигации проекта.
