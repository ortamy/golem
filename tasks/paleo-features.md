# Палео-фишки GOLEM (после UX/UI-редизайна)

> Статус: Запланировано (после завершения Linear-style редизайна)
> Создано: 2026-09-04
> Источник: идеи адаптации Linear UX под палео-тематику

## 8 палео-фишек для компактного интерфейса

### 1. Статусы «эмет/шекер» (как точки в Linear)
- `verified` → אמת зелёная печать 16px, tooltip "Проверено"
- `needs-review` → ? серая печать, tooltip "Требует проверки"
- `hypothesis` → ± золотая, tooltip "Гипотеза"
- `disputed` → ✕ красная, tooltip "Спорно"
- Без текста, только при hover — как status dots в Linear

### 2. Пустые состояния с печатью
- Вместо "Ничего не найдено" → тиснёная печать אין תוצאות
- Крупно, серый цвет, как watermarks в Linear
- Креативно + минималистично

### 3. Эволюция глифов при hover
- Карточка → hover на глифе → микро-анимация פ ← 𐤐 ← Proto-Sinaitic
- 3-4 кадра, 200ms, без навязчивости

### 4. Дерево корней в сайдбаре
- Разделы = корневые глифы вместо иконок (דבר, מלכות, כהונה)
- Компактные 24px, как sidebar в Linear

### 5. Progress-«швиа»
- Концентрические круги вместо progress-ring
- Заполненность = уровень исследования

### 6. Placeholder на иврите
- Поле поиска: "חפש שורש, דבר, אמת"
- При вводе иврита → автоподстановка глифов

### 7. Горячие клавиши — глифы
- `?` → overlay с shortcuts
- א = новый, ש = сохранить, מ = метка

### 8. Badge участника — печать
- Аватар = глиф-подпись (первый глиф имени)
- Как монограммы в Linear

## Приоритеты реализации
1. Статусы (высокий — самый заметный)
2. Пустые состояния (высокий)
3. Эволюция глифов (средний)
4. Дерево корней (средний)
5. Остальные — после тестирования первых

## Принципы
- Не превращать в визуальный мусор
- Палео-элементы функциональны, не декоративны
- Сохранять минимализм Linear
