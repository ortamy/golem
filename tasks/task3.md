ЗАДАЧА: Мобильный лендинг P1+P2 — таб-бар, waitlist, масштаб, интерактив

КОНТЕКСТ
- Публичный сайт: products/website/ (index.html / src/), пергамент/золото
- Секции уже в порядке: hero → карта утрат → механика (Мицраим) → свива →
  клуб → инструменты → методология → футер. Скругления есть.
- build/ — производный; после правок собирать. Vanilla JS + motion.

=== P1 ===

1. STICKY-НАВИГАЦИЯ
   1.1. Mobile (≤720px): нижний таб-бар, появляется после скролла hero:
        [Карта] [Механика] [Клуб] [Инструменты] — якоря с плавным скроллом.
        body получает padding-bottom, чтобы бар не перекрывал футер;
        учесть env(safe-area-inset-bottom).
   1.2. Desktop: тонкая якорная строка в шапке (те же 4 якоря), sticky.
   1.3. Секциям добавить id: #map #mechanics #club #tools.
   1.4. prefers-reduced-motion → без плавного скролла.

2. WAITLIST В КЛУБ-БЛОКЕ
   2.1. Под кнопкой «В палео-клуб →»: поле email + [Сообщить об открытии].
   2.2. Адаптер хранения: если подключён Supabase-клиент → insert в таблицу
        waitlist(email, created_at); иначе — очередь в localStorage
        golem_waitlist (синк позже). НЕ фейковать отправку.
   2.3. Валидация email; успех — сообщение «Вы в списке. Код придёт на почту.»;
        дубликаты — мягкое «Вы уже в списке».
   2.4. SQL для позже: create table waitlist(id bigint identity,
        email text unique, created_at timestamptz default now()); + RLS insert anon.

3. ЧЕТВЁРТАЯ КАРТОЧКА ИНСТРУМЕНТОВ
   3.1. «Палео-тренажёр»: описание «Собирай смысл из крупных палео-букв…»,
        кнопка «Открыть тренажёр ↗» → #learn/paleo-trainer (лаб).
   3.2. Под сеткой — ссылка «Все инструменты лаборатории →».

4. ПОЛОСА МАСШТАБА

   127 корней · 21 словарь · 23 046 стихов · 16 состояний · 22 буквы.

=== P2 ===

5. КАРТА УТРАТ: ТАП-РАСКРЫТИЕ
   Каждая строка — аккордеон; внутри 1–2 строки «что потерялось»:
   02 огласовка зафиксировала один вариант чтения;
   03 душа вместо жизни, дух вместо дыхания;
   04 закон вместо наставления, церковь вместо собрания;
   05 готовое понятие, Бог вместо Элоhим.
   Стрелка-индикатор раскрытия; aria-expanded.

6. БУКВЫ МИЦРАИМ — ТАПАБЕЛЬНЫЕ
   Тап по букве → поповер с образом и функцией (вода/поток, крюк/захват,
   вершина, рука/действие); закрытие по тапу вне/Escape; на desktop — hover.
   ПопOVER не вылезает за края (flip у границ).

7. SCROLL-ПРОГРЕСС + НАВЕРХ
   Тонкая золотая полоса сверху (2–3px), ширина = % прочитанного.
   Кнопка ↑ появляется после ~60% скролла, плавно вверх.

8. КОРОТКИЙ H1 НА MOBILE (≤480px)
   Полный: «Golem — исследовательская платформа для реконструкции
   палео-образного мышления». Короткий: «Реконструкция палео-образного
   мышления». Реализовать двумя span + media-query (не JS-заменой текста).

=== НЕ ЛОМАТЬ ===
- порядок секций, клуб-модалку и CLUB_URL, скругления, тёмную тему,
- пергаментную эстетику. build/ не править вручную.

=== ПРОВЕРКА (360/480/720px + desktop) ===
- Таб-бар появляется после hero, якоря скроллят, футер не перекрыт.
- Waitlist: валидация, успех, дубликат; localStorage-очередь растёт.
- 4 карточки инструментов + ссылка «все инструменты».
- Чипы масштаба скроллятся горизонтально на mobile.
- Утраты раскрываются тапом; буквы Мицраима дают поповер; Escape работает.
- Прогресс-полоса и ↑ работают; H1 короткий на ≤480px.
- reduced-motion: без плавных эффектов.
