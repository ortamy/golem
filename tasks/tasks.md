```
ЗАДАЧА: Страховка smoke-окружения + скрипт чистого запуска

1. playwright.config.js: globalTimeout 20*60*1000; test timeout 30000;
   expect timeout 5000; reporter line + json (test-results/smoke.json).
2. Создать tools/clean-smoke.ps1: убить зомби (headless_shell/chrome/
   playwright-процессы), удалить tests\screenshots\*.png и
   test-results\smoke.json, запустить npm run test:smoke --workers=1.
3. bugs.md не трогать до зелёного прогона.

НЕ ЛОМАТЬ: маршруты, данные, стили.
ОТЧЁТ: diff конфига; содержимое clean-smoke.ps1; команда для пользователя
(запуск ВНЕ VS Code).
```

> После отчёта вы сами запускаете `tools/clean-smoke.ps1` в свежем PowerShell.

## 📌 Правило последовательности

Не запускать задачу N+1, пока задача N не дала зелёный smoke и отчёт. Промпты подаёте по одному — так контекст Cline не раздувается и каждая задача проверяема.

Начинайте с задачи 1. Пришлите её отчёт + результат clean-smoke.ps1 — и двинемся дальше.
