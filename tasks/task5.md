# Задача: Фаза 3 — Компоненты и навигация Research Lab

## Контекст

Фаза 2 завершена.
Фон очищен, типографика приведена в порядок, дашборд пересобран.

Теперь работаем с компонентами и навигацией:
- единые компоненты;
- спокойные микровзаимодействия;
- логичная навигация;
- без визуального шума.

## Что сделать строго по порядку

### 3a. Привести компоненты к единому виду

Компоненты:
- btn;
- card;
- alert;
- input;
- textarea;
- select;
- tab;
- modal.

Для каждого:
- один базовый стиль;
- состояния: default, hover, active, disabled, focus;
- радиусы и отступы только из токенов;
- без точечных стилей в модулях.

### 3b. Обновить навигацию

- убрать дубликаты и скрытые alias-пункты;
- построить навигацию по актуальной конфигурации роутера;
- сгруппировать анализаторы логично;
- sidebar-item: спокойная активная полоса 2px;
- hover без резких сдвигов.

### 3c. Микровзаимодействия

- стандартная длительность: 0.2s;
- быстрые hover: 0.15s;
- убрать translateY(6px);
- hover-смещение: не более -2px;
- без каскадных задержек;
- появление модулей: fadeIn 0.2s ease.

### 3d. Иконки

- проверить актуальные иконки;
- убрать лишние PNG там, где уже есть SVG;
- placeholder.svg оставить только как служебную заглушку;
- не добавлять новые PNG.

### 3e. Footer

- убрать формулировки, выбивающиеся из методологии;
- оставить спокойный служебный блок;
- без религиозной или лозунговой нагрузки.

## Ограничения

- не менять контент;
- не трогать палео-логику;
- не удалять белую тему;
- не менять цветовую ДНК;
- коричневые и пастельные оттенки сохранить;
- золото — единственный смысловой акцент.

## Результат

- компоненты единообразны;
- навигация чистая;
- микровзаимодействия быстрые;
- иконки в порядке;
- footer спокойный;
- краткий отчёт о сделанном.
