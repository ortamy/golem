Задача: Изменить загрузку пайплайнов в разделе «Пайплайны» модуля «AI-Агенты» так, чтобы они отображались из локального JSON, даже если сервер не запущен.

Сейчас пайплайны загружаются через API (http://localhost:5000/api/pipelines). Если сервер не запущен, страница показывает ошибку и пайплайны не видны.

Требования:

1. Создать локальный JSON-файл `data/pipelines.json` с тремя пайплайнами (word_analyzer, verse_comparator, research_builder).

2. В `page-controller.js` изменить загрузку пайплайнов:
   - Сначала пытаться загрузить из `data/pipelines.json`.
   - Если локальный файл есть — отобразить его.
   - Если локального файла нет — пытаться загрузить через API.

3. Статус сервера (`localhost:5000`) проверять отдельно и отображать в виде индикатора (например, зелёный кружок «Сервер запущен» / серый «Сервер отключен»).

4. Проверить, что:
   - Пайплайны отображаются при загрузке страницы, даже если сервер не запущен.
   - При запуске сервера пайплайны остаются видимыми.
   - Индикатор статуса сервера показывает правильное состояние.
