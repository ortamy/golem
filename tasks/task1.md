# Задача: Расширить глобальный поиск на все разделы («Палео-поиск»)

**Контекст:** Сейчас поиск (`LabSearch`) работает только по корням и словарям. Нужно расширить его на все основные разделы: Методология, Картография, Гербовник, Книгочтение.

**Цель:** Сделать поиск глобальным. При вводе запроса система должна искать по всем разделам и показывать результаты с указанием раздела-источника.

---

## Указания для Cline

### 1. Открой `js/lab-search.js` (или встроенный `LabSearch`)
Найди функцию `search()`, которая сейчас фильтрует только корни и словари.

### 2. Добавь поиск по разделам
Расширь логику поиска:
- **Методология** — искать по названиям карточек и табов.
- **Картография** — искать по названиям стран, городов, регионов.
- **Гербовник** — искать по названиям стран и символов.
- **Книгочтение** — искать по названиям книг и стихам.

### 3. Отображение результатов
- Каждый результат должен содержать: **найденный текст**, **раздел-источник** и **ссылку на переход**.
- Результаты группируй по разделам.

### 4. Проверка
- Перезагрузи лабораторию.
- Введи поисковый запрос (например, «Мицраим» или «Ангел»).
- Убедись, что результаты приходят из всех разделов и кликабельны.

---

## Критерий готовности
- Поиск работает по всем разделам.
- Результаты показывают раздел-источник.
- Клик по результату переходит в нужный раздел.
