# Задача: Фаза 2 — Layout и типографика Research Lab

## Контекст

Фаза 1 завершена.
Токены spacing, радиусов, теней, цветов и типографики введены.

Теперь пересобираем layout и типографику:
- убираем визуальный шум;
- делаем интерфейс спокойнее;
- сохраняем тёплую коричнево-пастельную идентичность;
- референс — Linear.

## Что сделать строго по порядку

### 2a. Очистить фон

Убрать:
- текстуры;
- шумы;
- watermark-слои;
- повторяющиеся градиенты;
- декоративные подложки.

Оставить:
- ровный тёплый фон;
- спокойные поверхности;
- мягкие границы.

### 2b. Привести заголовки в порядок

- line-height: 1.4 для заголовков;
- убрать наследование 1.8 от body;
- применить типографическую шкалу;
- убрать случайные размеры;
- заголовки — сдержанные, без декоративной театральности.

### 2c. Пересобрать дашборд

- убрать лишние обводки;
- убрать тяжёлые тени;
- сделать карточки спокойнее;
- уменьшить hover-смещения;
- оставить золото точечным акцентом;
- плотность — как у рабочего инструмента.

### 2d. Переработать hero-блок

- без декоративной рамки-коробки;
- тёмный тёплый фон;
- один золотой акцент;
- крупный, но спокойный заголовок;
- меньше «старины ради старины».

### 2e. Упростить карточки

- фон + тонкая граница;
- без постоянной тени;
- hover — мягкий;
- радиус — из токенов;
- внутренние отступы — по spacing-шкале.

## Ограничения

- не менять контент;
- не трогать палео-логику;
- не удалять белую тему;
- не менять цветовую ДНК;
- коричневые и пастельные оттенки сохранить;
- золото — единственный смысловой акцент.

## Результат

- фон ровный, тёплый, спокойный;
- типографика читается;
- дашборд стал инструментом, а не витриной;
- карточки мягче;
- hero без декоративного шума;
- краткий отчёт о сделанном.
