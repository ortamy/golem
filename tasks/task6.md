# Задача: Фаза 4 — Глубокий рефакторинг Research Lab

## Контекст

Фаза 3 завершена.
Компоненты и навигация приведены в порядок.

Теперь убираем архитектурный хаос:
- инлайн-разметка из JS;
- безусловная загрузка всех модулей;
- дублирование источников стилей.

Это самая глубокая фаза.
Она не должна ломать текущий интерфейс.

## Что сделать строго по порядку

### 4a. Вынести инлайн-разметку из JS

Найти:
- строки с `style=`;
- создание разметки через `innerHTML` с CSS;
- inline-стили в JS-модулях.

Перенести:
- в классы;
- в шаблонные функции;
- в компонентные модули.

### 4b. Убрать безусловную загрузку модулей

Сейчас грузятся все CSS и JS модулей.
Нужно:
- загружать CSS и JS только при открытии страницы;
- использовать ленивую загрузку;
- маршрут открылся — подтянулся его модуль.

### 4c. Навести порядок в подключениях

- убрать дубли `<link>`;
- убрать мёртвые файлы;
- проверить зависимости;
- оставить один входной файл стилей;
- модули подключают только свои компоненты.

### 4d. Проверить темы

Убедиться:
- light;
- white;
- dark.

Работают без регрессий.
Ни один модуль не вводит свои цвета в обход токенов.

### 4e. Финальный прогон

Пройти по всем маршрутам:
- нет ошибок в консоли;
- нет пустых страниц;
- нет сорванных стилей;
- нет потерянных иконок;
- скорость открытия страниц не ухудшилась.

## Ограничения

- не менять контент;
- не трогать палео-логику;
- не удалять белую тему;
- не менять цветовую ДНК;
- коричневые и пастельные оттенки сохранить;
- золото — единственный смысловой акцент;
- без визуальных регрессий.

- модули загружаются лениво;
- дубли подключений устранены;
