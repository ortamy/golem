## Поэкранный разбор

### Рабочий стол (#dashboard)
- Хорошо: метрики-строка с serif-числами (300 / 1913 / 205 / 21 / 40) — читаемая иерархия; лента активности с датами; сайдбар с активным золотым маркером.
- Дёшево: битый логотип и битая иконка в hero; hero-плашка плоская; метрики без карточной глубины (числа «висят» на разделителях); подпись «срез данных» ×5.

### Манифест (#manifest)
- Хорошо: римская цифра «I» + caps-kicker + «Проблема» — настоящий манускрипт-приём; body-serif крупный, line-height комфортный; табы АКТ I–IV с золотым подчёркиванием активного.
- Дёшево: hero-плашка плоская; выравнивание в hero несогласовано (kicker слева, заголовок по центру); табы — простая бежевая полоса без глубины.

### Палео-клуб (#club)
- Хорошо: аватар-стек «МОСНС+1» с хвостом-переполнением; карточка сессии с вложенным highlight; двухколоночная сетка сдержанна.
- Дёшево: битая иконка в hero; primary-кнопка «Обсуждения» — плоская охра во всю ширину колонки (выглядит тяжело, не «дорого»); карточки без теней/hover; рамки-прямоугольники без ритма радиусов.

### Исследования (#researches)
- Хорошо: палео-глифы инлайном в тексте карточек (ה) работают; caps-«КЛЮЧЕВЫЕ ТЕРМИНЫ»; pill-тег «АНАТОМИЯ»; счётчик «205 из 205».
- Дёшево: **битые иконки на карточках** (главный визуальный мусор экрана); бейдж «ТРЕБУЕТ ПРОВЕРКИ» — плоский, не кодирует уровень уверенности; чипы-фильтры без активной заливки; карточки без hover-глубины.

### Обучение (#learn)
- Хорошо: stat-тайлы выровнены сеткой; цветные верхние рамки карточек уроков (зелёная/золотая) — намёк на статусы.
- Дёшево: битая иконка в hero; «Сбросить прогресс» — крупный красный контур на видном месте (destructive должен быть тише); регистр подписей «0 ОЧКОВ» против «0/22»; тайлы без фона/тени.

### Mobile (#dashboard, 390px)
- Хорошо: хедер складывается в иконочную строку; метрики складываются вертикально с разделителями; overflow нет (smoke гейтит).
- Дёшево: hero — половина первого экрана при 3 строках пользы + битая иконка; вертикальный стек метрик монотонен (все ячейки одинаковой важности).

## Что уже хорошо (не трогать)

- Serif-типографика EB Garamond/Cormorant и капитель-kicker — костяк «манускрипта» уже есть.
- Палитра пергамент/золото консистентна (токены, 4 темы); инлайн палео-глифы в текстах.
- Сетки и shells (`--shell-*`) выдержаны; mobile не переполняется.
- Токен-база (типографика, тени, motion) готова — проблема в **применении**, а не в отсутствии системы.

## Приёмка этапов B/C (критерии)

- `test:smoke:quick` после этапа B; полный smoke `68/68` + `134 PNG` после этапа C.
- Нет mobile overflow (гейт smoke), тёмная тема без деградации контраста (AA), `prefers-reduced-motion` выключает reveal/shimmer/spotlight.
- Before/after: `tools/design-baseline` — снять v8 после применения, `compare.mjs v7 v8`, ревью хит-карт; вручную — 5–6 пар экранов.
- P0-блок №1–2 чинится в начале этапа C (битые ассеты), иначе «after» наследует визуальный мусор.
