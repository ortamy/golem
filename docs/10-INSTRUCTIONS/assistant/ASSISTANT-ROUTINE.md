# CLINE-ROUTINE.md — Алгоритм ежедневной работы для Cline

**Файл:** `CLINE-ROUTINE.md`  
**Версия:** 1.0  
**Статус:** Активный  
**Тема:** Алгоритм ежедневной работы для Cline  
**Связанные файлы:** `docs/TECHNICAL-DEBT.md`, `CONTROL.md`, `docs/IDEAS.md`

---

## Полная воронка

Каждый день Cline выполняет этот алгоритм. Ты только подтверждаешь результаты.

---

## Этап 1: Проверки

**1.1 Религионизмы**  
`python tools/checkers/check-religionisms.py --fix`  
Доклад: сколько файлов, сколько замен.

**1.2 Битые ссылки**  
`python tools/checkers/check-links.py --fix`  
Доклад: сколько битых, сколько исправлено.

**1.3 Пустые файлы**  
`python tools/checkers/check-empty-files.py`  
Доклад: сколько пустых, сколько с маркерами.

**1.4 Имена файлов**  
`python tools/checkers/check-naming.py`  
Доклад: сколько нарушений.

**1.5 Качество кода**  
`python tools/checkers/check-code-quality.py`  
Доклад: сколько проблем, типы.

---

## Этап 2: Технический долг

**2.1 Прочитать** `docs/TECHNICAL-DEBT.md`.

**2.2 Взять задачи с маркером `- [ ]`**  
Сортировать: сначала те, что можно сделать быстро (один файл, простая замена).  
Доклад: какие задачи берёт в работу.

**2.3 Выполнить задачи**  
По одной. После каждой — доклад, что сделано.

**2.4 Отметить выполненные**  
Заменить `- [ ]` на `- [x]` в `TECHNICAL-DEBT.md`.

---

## Этап 3: Новые исследования

**3.1 Пустые файлы из этапа 1.3**  
Взять каждый пустой файл. Прочитать похожие файлы для примера. Написать исследование по шаблону. Сохранить.

**3.2 Новые темы из IDEAS.md**  
`docs/IDEAS.md` → найти невыполненные. Предложить 3 самые важные. После подтверждения — написать.

---

## Этап 4: Обновление проекта

**4.1 Структура**  
`python tools/sync/sync-structure.py`

**4.2 Веб-интерфейс**  
`python tools/generators/generate-files-json.py`

**4.3 Кэш знаний (раз в неделю)**  
`python ed-neural/scripts/generate-knowledge-cache.py --rebuild`

---

## Этап 5: Доклад

**5.1 Итоги дня**  
- Что сделано  
- Что осталось  
- Что требует внимания человека  

**5.2 Обновить CONTROL.md**  
Отметить выполненные задачи дня. Добавить новые на завтра.

---

## Быстрый запуск

Скопируй этот промпт и отправь Cline:

---

«Прочитай файл CLINE-ROUTINE.md. Выполни все 5 этапов последовательно. На каждом этапе докладывай краткий результат. Не спрашивай подтверждения для операций, которые не удаляют файлы. Для удаления файлов или переименования — спроси подтверждение. В конце покажи итоговый отчёт.»
