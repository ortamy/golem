## ВВЕДЕНИЕ

В палео-иврите нет абстрактных «настроений» или «эмоций». Есть **состояния материи и пространства**. Каждое состояние можно диагностировать, измерить и, при необходимости, перейти в другое.

Эти семнадцать состояний — **не философия**. Это **физика пространства**.

**Палео-образ физики:** 𐤌·𐤃·𐤃 — измерять, протягивать.
𐤌 (поток) + 𐤃 (проход) + 𐤃 (проход) = поток, который проходит через проход к другому проходу.
Физика — это измерение потока через пространство.

Состояния описываются **на двух уровнях**:

1. **Народ Элоhим (ТаНаХ)** — путь от Авраhама до возвращения из плена.
2. **Община (Башах)** — путь обновлённого союза от Йешуа до восстановления.

### 1. Тоху (𐤕𐤅𐤄) — запертость

- **Стих:** Берешит 1:2 — «земля же была тоху».
- **Палео-образы:** 𐤕 (фиксация) + 𐤅 (связка) + 𐤄 (проявление)

- **Палео-механика:** Фиксация (𐤕) запечатывает пространство. Связка (𐤅) пытается открыть. Проявление (𐤄) не наступает. Поток есть, но выход перекрыт.
- **Физика:** Герметичный контур. Нет входа. Нет выхода. Нет движения.
- **В теле:** Сжатие в груди, ощущение стены, неглубокое дыхание.
- **В жизни:** Творческий ступор, замкнутый круг, системная ловушка.
- **Народ Элоhим (ТаНаХ):** Вавилонский плен — народ заперт вне своей земли.
- **Община (Башах):** Община, запертая в религиозной системе без живого потока.
- **Примеры:** Комната без окон, закрытая система, зависимость.

## ДАВАР КАК ИНСТРУМЕНТ ПЕРЕХОДА

Все переходы осуществляются через Давар (𐤃𐤁𐤓).

**Палео-механика Давар:**

- 𐤃 (Далет) — проход, дверь.
- 𐤁 (Бет) — вместилище, дом.
- 𐤓 (Реш) — вершина, голова.

**Визуальная сборка:** Проход (𐤃) открывает вместилище (𐤁), чтобы выпустить содержимое через вершину (𐤓).

**Функция:** Действие через открытие прохода.

**Как это работает:**

1. Осознай текущее состояние.
2. Произнеси Давар — команду на переход.
3. Открой дверь и перейди.

**Примеры Давар-переходов:**

- Из Мицраима в Эвр → «Я прохожу через границу».
- Из Хошех в Шамаим → «Я разжимаю систему».
- Из Тоху в Эрец → «Я строю опору».
- Из Шеола в Жизнь → «Я встаю из остановки».
- Из Тхом в Шамаим → «Я выпускаю давление».
- Из Боху в Эрец → «Я наполняю пустоту».
- Из Ган в Эден → «Я вхожу в завершённость».
- Из Олам в Эрец → «Я возвращаюсь к опоре».
