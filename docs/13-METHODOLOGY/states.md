**Файл:** `methodology/states.md`
**Версия:** 2.5
**Дата создания:** 2026-07-31
**Последнее обновление:** 2026-08-23
**Причина обновления:** Добавлены состояния Боху, Тхом, Шаббат, Ган, Олам. Карта теперь содержит шестнадцать состояний, сгруппированных по блокам. Добавлены переходы и Давар-переходы для новых состояний.
**Тема:** Шестнадцать состояний пространства в палео-механике. Каждое состояние — это не метафора, а физическая конструкция.

---

## ВВЕДЕНИЕ

В палео-иврите нет абстрактных понятий «настроения» или «эмоции». Есть **состояния материи и пространства**. Каждое состояние можно диагностировать, измерить и, при необходимости, перейти в другое.

Эти шестнадцать состояний — **не философия**. Это **физика пространства**.

**Палео-образ физики:** 𐤌·𐤃·𐤃 — измерять, протягивать. 𐤌 (поток) + 𐤃 (проход) + 𐤃 (проход) = поток, который проходит через проход к другому проходу. Физика — это измерение потока через пространство.

## ГРУППА 1: НАЧАЛО

### 1. Тоху (𐤕𐤅𐤄) — запертость

- **Палео-образы:** 𐤕 (фиксация) + 𐤅 (связка) + 𐤄 (проявление)
- **Визуальная сборка:** «Запечатанное пространство с одной щелью»
- **Палео-механика:** Фиксация (𐤕) запечатывает пространство, связка (𐤅) пытается открыть, но проявление (𐤄) не наступает.
- **Физика:** Пространство герметично. Нет входа. Нет выхода. Нет движения.
- **В жизни:** Творческий ступор, замкнутый круг, системная ловушка.
- **Примеры:** Комната без окон, закрытая система, зависимость.
- **`root_ref`:** `roots.json#tohu`

**Что делать:** Ищи выход — дверь, проход, новый контакт. Не жди, пока кто-то откроет за тебя. Ищи сам.

---

### 2. Боху (𐤁𐤄𐤅) — пустота, разорванность

- **Палео-образы:** 𐤁 (вместилище) + 𐤄 (проявление) + 𐤅 (связка)
- **Визуальная сборка:** «Пустое вместилище, которое связка не наполняет»
- **Палео-механика:** Вместилище (𐤁) проявляется (𐤄), но связка (𐤅) не соединяет его с потоком. Внутри пусто.
- **Физика:** Пространство есть, но оно пустое. Нет содержимого. Нет связей.
- **В жизни:** Опустошённость, бессмысленность, отсутствие связей.
- **Примеры:** Пустая квартира, потеря смысла, разорванные отношения.
- **`root_ref`:** `roots.json#bohu` (требует проверки)

**Что делать:** Наполняй. Ищи связь. Не жди, пока пустота заполнится сама. Создавай содержимое и соединяй.

---

### 3. Хошех (𐤇𐤔𐤊) — сжатость

- **Палео-образы:** 𐤇 (граница) + 𐤔 (огонь) + 𐤊 (удержание)
- **Визуальная сборка:** «Сжатая масса, которая не пропускает»
- **Палео-механика:** Граница (𐤇) сжимает, огонь (𐤔) пытается пройти, но удержание (𐤊) не отпускает.
- **Физика:** Пространство плотное, непроницаемое. Ни воздух, ни идеи не проходят.
- **В жизни:** Эмоциональная закрытость, сопротивление новому.
- **Примеры:** Защитная броня, плотная среда, изоляция.
- **`root_ref`:** `roots.json#choshech`

**Что делать:** Дыши. Не сжимайся в ответ. Сделай полный выдох — это ослабляет хватку. Затем позволь вдоху прийти самому.

---

### 4. Тхом (𐤕𐤄𐤅𐤌) — бездна, глубина, давление

- **Палео-образы:** 𐤕 (фиксация) + 𐤄 (проявление) + 𐤅 (связка) + 𐤌 (поток)
- **Визуальная сборка:** «Поток, запертый фиксацией и давящий изнутри»
- **Палео-механика:** Поток (𐤌) связан связкой (𐤅), но фиксация (𐤕) не даёт ему выйти. Проявление (𐤄) заблокировано. Давление растёт.
- **Физика:** Глубина, где вода давит. Нет выхода. Только давление.
- **В жизни:** Подсознательный страх, подавленные чувства, накопленное напряжение.
- **Примеры:** Океанская бездна, запертый пар, невысказанная боль.
- **`root_ref`:** `roots.json#thom` (требует проверки)

**Что делать:** Выпускай давление постепенно. Не взрывайся. Найди клапан — разговор, движение, творчество. Выпусти поток контролируемо.

## ГРУППА 2: ДВИЖЕНИЕ

### 5. Ракиа (𐤓𐤒𐤉𐤏) — разделение / растяжение

- **Палео-образы:** 𐤓 (вершина) + 𐤒 (пронзание) + 𐤉 (действие) + 𐤏 (наблюдение)
- **Визуальная сборка:** «Рука растягивает пространство, пронзённое иглой»
- **Палео-механика:** Вершина (𐤓) направляет пронзание (𐤒) через действие (𐤉) к наблюдению (𐤏) — рука растягивает пространство, пронзённое иглой.
- **Физика:** Создание границы, разделяющей потоки.
- **В жизни:** Момент, когда ты отделяешь естественное от искусственного.
- **`root_ref`:** `roots.json#raqia`

**Что делать:** Разделяй то, что должно быть разделено. Бери нож, режь то, что не должно быть вместе. Создавай границу.

---

### 6. Шамаим (𐤔𐤌𐤉𐤌) — открытость

- **Палео-образы:** 𐤔 (огонь) + 𐤌 (поток) + 𐤉 (действие) + 𐤌 (поток)
- **Визуальная сборка:** «Огонь, прошедший через воду и направленный рукой»
- **Палео-механика:** Огонь (𐤔) проходит через поток (𐤌) и направляется действием (𐤉) в поток (𐤌).
- **Физика:** Пространство проницаемое. Поток двигается свободно.
- **В жизни:** Свободное движение, уверенность, лёгкость.
- **Примеры:** Открытое поле, атмосфера, движение без усилий.
- **`root_ref`:** `roots.json#shamayim`

**Что делать:** Строй, пока есть ветер. Делай Давар. Сейчас — лучшее время для действия, потому что ничто не мешает потоку.

---

### 7. Мицраим (𐤌𐤑𐤓𐤉𐤌) — теснота

- **Палео-образы:** 𐤌 (поток) + 𐤑 (захват) + 𐤓 (вершина) + 𐤉 (действие) + 𐤌 (поток)
- **Визуальная сборка:** «Вода, перехваченная захватом и перенаправленная рукой»
- **Палео-механика:** Поток (𐤌) захватывается захватом (𐤑), поднимается к вершине (𐤓), направляется действием (𐤉) и возвращается в поток (𐤌), но уже не свободным.
- **Физика:** Искусственный канал. Ты движешься, но не свободно.
- **В жизни:** Городская суета, офисная рутина, система контроля.
- **Примеры:** Метро, аэропорт, офис, очереди.
- **`root_ref`:** `roots.json#mitzrayim`

**Что делать:** Ищи Эвр — проход через границу. Не пытайся изменить канал изнутри. Ищи выход.

---

### 8. Эвр (𐤏𐤁𐤓) — прохождение / переход через границу

- **Палео-образы:** 𐤏 (наблюдение) + 𐤁 (вместилище) + 𐤓 (вершина)
- **Визуальная сборка:** «Глаз, видящий проход через вместилище к вершине»
- **Палео-механика:** Наблюдение (𐤏) видит проход через вместилище (𐤁) к вершине (𐤓).
- **Физика:** Прохождение сквозь преграду.
- **В жизни:** Момент пересечения границы между старым и новым.
- **`root_ref`:** `roots.json#evr`

**Что делать:** Продолжай двигаться. Не останавливайся. Не жди, пока «станет ясно». Ясность приходит после того, как ты прошёл.

---

### 9. Мидбар (𐤌𐤃𐤁𐤓) — движение / поиск

- **Палео-образы:** 𐤌 (поток) + 𐤃 (проход) + 𐤁 (вместилище) + 𐤓 (вершина)
- **Визуальная сборка:** «Вода, проходящая через проход пустого вместилища к вершине»
- **Палео-механика:** Поток (𐤌) проходит через проход (𐤃) пустого вместилища (𐤁) и направляется к вершине (𐤓).
- **Физика:** Ты в движении. Ты ищешь. Ты калибруешься.
- **В жизни:** Путешествие, исследование, переезд, разведка.
- **Примеры:** Дорога, пустыня, лес, новый город.
- **`root_ref`:** `roots.json#midbar`

**Что делать:** Исследуй, пробуй, ошибайся. Ты не потерян — ты ищешь. Ошибки — это не провалы, а калибровка.

- **Физика:** Пространство завершено. Жизнь течёт непрерывно.
- **В жизни:** Спокойствие, целостность, прибытие.

## ГРУППА 4: ОСТАНОВКА

### 13. Мавет (𐤌𐤅𐤕) — остановка потока

- **Палео-образы:** 𐤌 (поток) + 𐤅 (связка) + 𐤕 (фиксация)
- **Визуальная сборка:** «Поток, зафиксированный связкой»
- **Палео-механика:** Поток (𐤌) связывается связкой (𐤅) и фиксируется знаком (𐤕). Движение остановлено.
- **Физика:** Поток остановлен. Дыхание прервано. Тело не движется.
- **В жизни:** Смерть, прекращение, конец цикла.
- **Примеры:** Остановка сердца, конец проекта, завершение отношений.
- **`root_ref`:** `roots.json#mavet` (требует проверки)

**Что делать:** Не бойся. Мавет — это дверь, а не конец. Прими остановку как переход. Не держись за то, что уже остановилось.

---

### 14. Шеол (𐤔𐤀𐤅𐤋) — пребывание в остановке

- **Палео-образы:** 𐤔 (огонь) + 𐤀 (сила) + 𐤅 (связка) + 𐤋 (направление)
- **Визуальная сборка:** «Огонь, который сила уводит через связку в направлении вниз»
- **Палео-механика:** Огонь (𐤔) погас. Сила (𐤀) остановилась. Связка (𐤅) оборвалась. Направление (𐤋) ушло вниз.
- **Физика:** Тишина. Забвение. Отсутствие движения и хвалы.
- **В жизни:** Депрессия, забвение, состояние «меня нет».
- **Примеры:** Могила, заброшенное место, потеря памяти.
- **`root_ref`:** `roots.json#sheol` (требует проверки)

**Что делать:** Помни: Шеол — не вечен. Яхве выводит из Шеола. Держись за нить жизни. Жди вставания (𐤒𐤅𐤌).

**Важно:** Шеол — это не ад. Это не место мучений. Это состояние остановки, из которого можно выйти.

- **Теhилим 16:10** — «не оставишь души моей в Шеоле».
- **Теhилим 30:4** — «из Шеола поднял меня».
- **hОшеа 13:14** — «от Шеола искуплю их».

### 15. Шаббат (𐤔𐤁𐤕) — покой, остановка для Яхве

- **Палео-образы:** 𐤔 (огонь) + 𐤁 (вместилище) + 𐤕 (фиксация)
- **Визуальная сборка:** «Огонь, который во вместилище зафиксирован»
- **Палео-механика:** Огонь (𐤔) не сжигает, а согревает. Вместилище (𐤁) принимает. Фиксация (𐤕) удерживает покой.
- **Физика:** Остановка, в которой поток не прерывается, а восстанавливается.
- **В жизни:** Покой, восстановление, тишина без тревоги.
- **Примеры:** Суббота, отдых, молитва.
- **`root_ref`:** `roots.json#shabbat` (требует проверки)

**Что делать:** Остановись. Не делай. Просто будь. Позволь потоку восстановиться. Не путай Шаббат с ленью — это не бездействие, а наполнение.

## ГРУППА 5: СКРЫТОСТЬ

### 16. Олам (𐤏𐤅𐤋𐤌) — скрытый горизонт

- **Палео-образы:** 𐤏 (наблюдение) + 𐤅 (связка) + 𐤋 (направление) + 𐤌 (поток)
- **Визуальная сборка:** «Наблюдение, которое связкой направляет поток вдаль»
- **Палео-механика:** Наблюдение (𐤏) смотрит вперёд. Связка (𐤅) соединяет с тем, что впереди. Направление (𐤋) уводит поток (𐤌) за горизонт.
- **Физика:** Даль, которая скрыта. Будущее, которое ещё не проявилось.
- **В жизни:** Неизвестность, будущее, вечность.
- **Примеры:** Горизонт, даль, мечта о будущем.
- **`root_ref`:** `roots.json#olam` (требует проверки)

**Что делать:** Не бойся скрытого. Не пытайся увидеть всё сразу. Двигайся вперёд, даже если горизонт неясен.

## СЛОВАРЬ ПЕРЕХОДОВ

Некоторые слова в ТаНаХе являются не состояниями, а **переходами** — моментами, когда поток проходит через границу.

### Ям Суф (𐤉𐤌 𐤎𐤅𐤐) — Ворота выхода из Мицраима
- **Функция:** Выход из Мицраима в Мидбар. Вода разделяется, и народ проходит.
- **Направление:** Мицраим → Эвр → Ракиа → Мидбар.

### Иордан (𐤉𐤓𐤃𐤍) — Ворота входа в Эрец
- **Функция:** Вход из Мидбара в Эрец. Река останавливается, и народ переходит.
- **Направление:** Мидбар → Эрец.

### Эвр (𐤏𐤁𐤓) — переход через границу
- **Функция:** Прохождение сквозь преграду.
- **Направление:** Мицраим → Эвр → Ракиа → Шамаим.

### Ракиа (𐤓𐤒𐤉𐤏) — разделение / растяжение
- **Функция:** Создание границы, разделяющей потоки.
- **Направление:** Эвр → Ракиа → Шамаим.

### Мавет (𐤌𐤅𐤕) → Шеол (𐤔𐤀𐤅𐤋) — переход через дверь
- **Функция:** Остановка потока (Мавет) переходит в пребывание в остановке (Шеол).
- **Направление:** Жизнь → Мавет → Шеол.

### Шеол (𐤔𐤀𐤅𐤋) → Жизнь — вставание (𐤒𐤅𐤌)
- **Функция:** Выход из остановки через вставание.
- **Направление:** Шеол → Вставание (𐤒𐤅𐤌) → Жизнь.

### Шаббат (𐤔𐤁𐤕) → Жизнь — восстановление
- **Функция:** Выход из покоя в обновлённое движение.
- **Направление:** Шаббат → Жизнь.

## ДАВАР КАК ИНСТРУМЕНТ ПЕРЕХОДА

Все переходы между состояниями осуществляются через **Давар (𐤃𐤁𐤓)**.

**Палео-механика Давар:**
- **𐤃 (Далет)** — проход, дверь.
- **𐤁 (Бет)** — вместилище, дом.
- **𐤓 (Реш)** — вершина, голова.

**Визуальная сборка:** Проход (𐤃) открывает вместилище (𐤁), чтобы выпустить содержимое через вершину (𐤓).

**Функция:** Действие через открытие прохода.

Давар — это **не слово**. Это **открытие двери** через **выпуск содержимого** и **направление в новое состояние**.

**`root_ref`:** `roots.json#davar`

**Как это работает:**
1. Ты **осознаёшь** своё текущее состояние.
2. Ты **произносишь Давар** (вслух или про себя) — команду на переход.
3. Ты **открываешь дверь** и **переходишь** в новое состояние.

**Примеры Давар-переходов:**
- Из **Мицраима** в **Эвр** → «Я прохожу через границу».
- Из **Хошех** в **Шамаим** → «Я разжимаю систему».
- Из **Тоху** в **Эрец** → «Я строю опору».
- Из **Жизни** в **Мавет** → «Я прохожу через дверь».
- Из **Шеола** в **Жизнь** → «Я встаю из остановки».
- Из **Тхом** в **Шамаим** → «Я выпускаю давление».
- Из **Боху** в **Эрец** → «Я наполняю пустоту».

**Хук Свива для Давар:** Давар создаёт среду перехода. Из Мицраима (теснота) → через Давар → в Шамаим (открытость). Давар — это дверь, которая открывает переход.
