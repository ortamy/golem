**Файл:** `TANAKH-BASHAH-STATES-MAP.md`
**Версия:** 1.0
**Тема:** Навигация по книгам Писания через состояния палео-ивритской механики.
**Основание:** `MANIFEST.md` v10.1, `states.md`

---

## О документе

Этот документ не является «богословским обзором».  
Он говорит о том, **через какие состояния проходит поток** в каждой книге.

Каждая книга ТаНаХа и БаШаХа — это не текст, а **маршрут**.  
Она ведёт читателя от одного состояния к другому: от тесноты к поиску, от поиска к опоре, от опоры к завершённости.

### 𐤕𐤅𐤓𐤄 (Тора) — Наставление

**𐤁𐤓𐤀𐤔𐤉𐤕 (Берешит) — Бытие**
- Палео-разбор названия: 𐤁 (дом) + 𐤓 (вершина) + 𐤀 (сила) + 𐤔 (огонь) + 𐤉 (рука) + 𐤕 (знак) = *«Дом, который вершина поднимает силой через огонь рукой к знаку»*.  
- Состояния: 𐤕𐤅𐤄 → 𐤇𐤔𐤊 → 𐤓𐤒𐤉𐤏 → 𐤔𐤌𐤉𐤌 → 𐤌𐤑𐤓𐤉𐤌 → 𐤏𐤁𐤓.  
- Ключевая механика: Создание среды, переход от хаоса к опоре.

**𐤔𐤌𐤅𐤕 (Шмот) — Исход**
- Палео-разбор названия: 𐤔 (огонь) + 𐤌 (поток) + 𐤅 (связка) + 𐤕 (знак) = *«Огонь, который поток связывает и запечатывает знаком»*.  
- Состояния: 𐤌𐤑𐤓𐤉𐤌 → 𐤏𐤁𐤓 → 𐤓𐤒𐤉𐤏 → 𐤌𐤃𐤁𐤓.  
- Ключевая механика: Выход из тесноты через разделение вод.

**𐤅𐤉𐤒𐤓𐤀 (Ваикра) — Левит**
- Палео-разбор названия: 𐤅 (связка) + 𐤉 (рука) + 𐤒 (пронзание) + 𐤓 (вершина) + 𐤀 (сила) = *«Связка, которую рука пронзает через вершину силой»*.  
- Состояния: 𐤌𐤃𐤁𐤓 → 𐤀𐤓𐤑 (временная).  
- Ключевая механика: Калибровка в поиске, контакт с Источником.

**𐤁𐤌𐤃𐤁𐤓 (Бамидбар) — Числа**
- Палео-разбор названия: 𐤁 (вместилище) + 𐤌 (поток) + 𐤃 (проход) + 𐤁 (вместилище) + 𐤓 (вершина) = *«Вместилище, где поток проходит через проход пустого дома к вершине»*.

- Ключевая механика: Испытания в пустыне, проверка потока.

**𐤃𐤁𐤓𐤉𐤌 (Дварим) — Второзаконие**
- Палео-разбор названия: 𐤃 (проход) + 𐤁 (вместилище) + 𐤓 (вершина) + 𐤉 (рука) + 𐤌 (поток) = *«Проход, через который вместилище выпускает содержимое рукой в поток»*.  
- Состояния: 𐤌𐤃𐤁𐤓 → 𐤀𐤓𐤑 → 𐤏𐤃𐤍.  
- Ключевая механика: Подготовка к входу в опору и завершённость.

## Как использовать эту карту

1.  Открой любую книгу из списка.
2.  Определи, через какое состояние она ведёт.
3.  Вернись к Манифесту и вспомни механику этого состояния.
4.  Читай книгу как **навигацию по переходу**, а не как историю.

**ТаНаХ и БаШаХ — это не религиозные тексты.**  
Это **инженерные пособия по управлению потоком жизни через состояния.**
