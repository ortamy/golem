## 1. ОБОСНОВАНИЕ

Палео-иврит (протохананейское / финикийское письмо) — это **древнейший слой**, в котором каждая буква была пиктограммой (образом). Квадратное письмо (ассирийский шрифт, א–ת) — это **поздняя интерпретация**, введённая после вавилонского плена (VI в. до н.э.).

Проект «Голем» реконструирует **палео-образное мышление**, поэтому все палео-разборы должны использовать **только палео-ивритские буквы (𐤀–𐤕)**.

## 2. ПАЛЕО-ИВРИТСКИЕ БУКВЫ (𐤀–𐤕)

- **𐤀** — Алеф: бык / голова быка → сила, мощь, начало.
- **𐤁** — Бет: дом / шатёр → вместилище, дом, внутри.
- **𐤂** — Гимель: верблюд → движение, перенос.
- **𐤃** — Далет: дверь → проход, вход, открытие.
- **𐤄** — Хе: окно / решётка → дыхание, откровение, выход.
- **𐤅** — Вав: крюк / колышек → связь, соединение, фиксация.
- **𐤆** — Зайн: оружие / меч → защита, нападение, разделение.
- **𐤇** — Хет: ограда / забор → отделение, граница, защита.
- **𐤈** — Тет: змея / клубок → оборачивание, свёртывание.
- **𐤉** — Йод: рука / предплечье → действие, творение, власть.
- **𐤊** — Каф: ладонь / согнутая рука → удержание, охват, фиксация.
- **𐤋** — Ламед: посох / палка → направление, ведение.
- **𐤌** — Мем: вода / волны → поток, жизнь, движение.
- **𐤍** — Нун: рыба / змея → жизнь, плодовитость.
- **𐤎** — Самех: опора / столб → поддержка, основание, устойчивость.
- **𐤏** — Айн: глаз / источник → видение, внимание, источник.
- **𐤐** — Пе: рот / отверстие → речь, открытие, дыхание.
- **𐤑** — Цади: крюк / ловушка → захват, фиксация, охота.
- **𐤒** — Коф: игла / затылок → отделение, фиксация, пронзание.
- **𐤓** — Реш: голова / вершина → начало, вершина, власть.
- **𐤔** — Шин: зуб / огонь → разрушение, проникновение.
- **𐤕** — Тав: знак / печать → завершение, подпись, фиксация.

## 3. ПРАВИЛА ПРИМЕНЕНИЯ

### 3.1. Где использовать палео-буквы

- Все палео-образы записываются через 𐤀–𐤕.
- Все корни записываются через 𐤀–𐤕 (например, 𐤒·𐤓·𐤁 вместо ק.ר.ב).
- Все визуальные сборки используют 𐤀–𐤕 как имена функций.
- Все разборы строятся на 𐤀–𐤕.

### 3.2. Где допускается квадратное письмо (א–ת)

Квадратное письмо (א–ת) допускается только в следующих случаях:

1. Цитаты из масоретского текста (например, `בְּרֵאשִׁית בָּרָא אֱלֹהִים`).
2. Указание современной ивритской формы (например, `תורה`).
3. Транслитерация (например, `Тора`).

### 3.3. Формат записи корней

- Корни записываются с точками между буквами: `𐤒·𐤓·𐤁`.
- Палео-образы записываются через пробел: `𐤒 𐤓 𐤁`.
- Визуальная сборка: `𐤒` (игла) + `𐤓` (голова) + `𐤁` (дом) = ...

## 4. ПРИМЕР

**Было (квадратное письмо):**
> `תורה` (Тора) — корень `י.ר.ה` — направлять.
> Палео-образы: `ת` (знак) + `ו` (крюк) + `ר` (голова) + `ה` (окно) = знак, который крюк направляет к голове через окно.

**Стало (палео-письмо):**
> `𐤕𐤅𐤓𐤄` (Тора) — корень `𐤉·𐤓·𐤄` — направлять.
> Палео-образы: `𐤕` (знак) + `𐤅` (крюк) + `𐤓` (голова) + `𐤄` (окно) = знак, который крюк направляет к голове через окно.
