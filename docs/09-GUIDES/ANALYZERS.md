## Что делают анализаторы

Модуль `tools/analyzers/` выполняет вертикальный проход по тексту. Он выделяет слова и предложения, затем последовательно проверяет восемь слоёв: эллинизацию, психологизацию, юридизацию, технослой, медиа-слой, религиозную кальку, палео-слой и физический слой.

Для каждого слоя движок считает уникальные слова текста, на которых найден хотя бы один маркер, и показывает их долю от общего числа слов. Отдельно выводятся частоты маркеров и примеры найденных слов. Процент — диагностический сигнал, а не доказательство подмены: итог следует сверять с протоколом разоблачения и критериями эмет / шекер.

Если текст содержит более 100 слов, запускается глубинный проход. Он ищет повторяющиеся слова, активные пары слоёв с внутренним напряжением и формирует рекомендации по возврату к предметному действию, телу и Свиве.

## Запуск

Из корня репозитория:

```bash
python tools/analyzers/analyze.py --text "Дверь открывает поток, но система превращает его в ресурс."
python tools/analyzers/analyze.py path/to/text.txt
type path\to\text.txt | python tools/analyzers/analyze.py --plain
```

Полезные режимы:

- `--plain` — отключить ANSI-цвета, удобно для перенаправления вывода и CI.
- `--json` — получить структурированный результат для дальнейшей обработки.
- `--help` — показать справку CLI.

Пример JSON-команды:

```bash
python tools/analyzers/analyze.py --text "Алгоритм управляет ресурсом." --json
```

## Расширение маркеров

Каталог находится в `tools/analyzers/markers.json`. Чтобы расширить существующий слой, добавьте объект в его список `markers`:

```json
{"term": "новый корень", "pattern": "новый", "scope": "word"}
```

Поле `pattern` — регулярное выражение без флагов; поиск нечувствителен к регистру. Значение `scope: "word"` проверяет отдельные слова и их корни. Значение `scope: "text"` предназначено для конструкций, например `"открывает\\s+дверь"`, и учитывает все слова, попавшие в найденный фрагмент.

Для каждого слоя также редактируются `diagnosis` и `recommendations`. Логика движка при этом не меняется.

Чтобы добавить новый слой, вставьте в массив `layers` полный объект с уникальным `id`, названием, описанием, списком маркеров, диагностикой и рекомендациями. При необходимости добавьте его `id` в `tensions`, чтобы глубинный проход распознавал новую пару слоёв.

## Проверка

```bash
python -m unittest discover -s tools/analyzers -p "test_*.py"
python tools/analyzers/analyze.py --text "Поток открывает дверь." --plain
```

Анализатор использует только стандартную библиотеку Python и не требует установки дополнительных пакетов.
