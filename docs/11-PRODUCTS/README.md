# 11-PRODUCTS — документация продуктов

> Обложка раздела генерируется автоматически: `python tools/generate-docs-index.py`.

## Файлы

- **AGENT.md** — Документация агента «Эд» — философия, архитектура, режимы работы, отличие от ассистента
- **ANALYZERS.md** — запуск, формат вывода и расширение каталога маркеров
- **ASSISTANT.md** — Документация ассистента «Эд» — философия, архитектура, команды, отличие от агента
- **DAVAR.md** — Язык программирования «Давар» — философия, архитектура, отличие от других языков
- **NEURO.md** — Документация нейросети «Эд» — архитектура, философия, отличие от коммерческих нейросетей
- **RESEARCH-LAB-MAP.md** — Карта Research Lab
- **RESEARCH-LAB.md** — Архитектура и функциональность исследовательской лаборатории — полноценного web-приложения для работы с текстами, переводами, корнями и нейр ⚠️ исторический
- **RESEARCHLAB-ANALYZERS.md** — веб-модуль для слоя, ИИ- и диалект-анализа
- **SETTINGS.md** — Документация модуля настроек и администрирования ResearchLab
- **WEB-INTERFACE.md** — Полная документация веб-интерфейса — архитектура, функционал, деплой ⚠️ исторический
- **WEBSITE.md** — Архитектура, структура и функциональность основного сайта проекта «Голем» — статического портала для публикации исследований, терминов, чтен ⚠️ исторический
