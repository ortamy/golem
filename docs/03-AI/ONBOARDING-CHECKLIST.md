# ONBOARDING-CHECKLIST.md — Полный чек-лист для передачи контекста в новый чат

**Файл:** `docs/03-AI/ONBOARDING-CHECKLIST.MD.md`  
**Версия:** 1.1  
**Статус:** Активный  
**Тема:** Список файлов, которые нужно передавать в новый чат для сохранения контекста проекта «Голем»

---

## Для чего нужен этот чек-лист

При переезде в новый чат (смена ассистента, новый AI-агент, обновление контекста) важно передать минимальный, но достаточный набор файлов, который описывает:

- Методологию проекта
- Архитектуру агентов
- Словари и данные
- Архитектуру сайта
- Текущие задачи
- Правила работы

Этот чек-лист позволяет быстро собрать и передать нужный контекст без потери времени.

---

## Группа 1. Ядро проекта (Философия и агенты)

Эти файлы обязательны для понимания методологии и архитектуры агентов.

1. `MANIFEST.md` — философия и методология проекта.
2. `PALEO-TRANSLATION-PROTOCOL.md` — правила перевода палео-иврита.
3. `docs/03-AI/AGENT-SYSTEM.MD.md` — описание всех агентов и их ролей.
4. `docs/03-AI/ARCHITECTURE.MD.md` — техническая структура папок, файлов и вызовов.
5. `docs/03-AI/AGENT-STATUS.MD.md` — текущий статус реализации каждого агента.
6. `docs/TECHNICAL-DEBT.md` — список открытых задач и технического долга.
7. `CLINE-ROUTINE.md` — ежедневный алгоритм работы ассистента.
8. `RESEARCH-LAB-MAP.md` - архитектурная карта проекта.

## Как передавать

В новом чате отправь одно сообщение с перечислением файлов:

> *«Передаю ключевые файлы проекта «Голем» для сохранения контекста. Список: MANIFEST.md, PALEO-TRANSLATION-PROTOCOL.md, AGENT-SYSTEM.md, ARCHITECTURE.md, AGENT-STATUS.md, TECHNICAL-DEBT.md, CLINE-ROUTINE.md, а также словари и архитектурные файлы из чек-листа.»*

Затем прикрепи файлы одно за другим.
